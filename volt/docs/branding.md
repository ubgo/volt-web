# Branding

Make Volt yours: swap the logo, favicon, and PWA icons, then update the app's name in a couple of places. This guide covers the fast path (one source image + one command) and every spot where branding is wired, so nothing keeps saying "Volt" after you rebrand.

There's a live version of this page in the app at `/demo/branding` — it renders every icon the app ships and where each one is used. The brand kit at [`../brand/`](../brand/README.md) is the canonical identity source (see [BRAND_GUIDELINES.md](../brand/BRAND_GUIDELINES.md)) if you want to regenerate the whole system rather than just replace assets.

## The fast path

1. **Prepare one square source image** — at least 512×512 (1024×1024 is ideal), PNG. Save it as `public/logo-source.png`, replacing the one that ships.
2. **Generate the icon set:**

   ```bash
   task branding:gen
   ```

   This runs `sips` (macOS) to produce three PNGs from your source:

   ```
   public/images/icon-192.png       # 192×192 — PWA manifest
   public/images/icon-512.png       # 512×512 — PWA install / splash
   public/images/icon-180x180.png   # 180×180 — Apple touch icon (iOS home screen)
   ```

3. **Replace the favicon and logos** (see below — `task branding:gen` does not write these).
4. **Update the names** in `public/manifest.json` and `src/lib/seo.ts`.
5. **Swap the sidebar logo** in `src/components/admin-shell.tsx`.
6. **Hard-refresh** — favicons cache aggressively (Cmd-Shift-R / Ctrl-F5).

## What ships, and what to replace

All runtime assets live in `public/` and are served from the site root as-is.

| Asset | Spec | Used by | Regenerated by `task branding:gen`? |
|-------|------|---------|-------------------------------------|
| `public/logo-source.png` | 1024×1024 PNG | Source for the icon set | No — this is your input |
| `public/images/icon-192.png` | 192×192 PNG | PWA manifest (`any maskable`) | Yes |
| `public/images/icon-512.png` | 512×512 PNG | PWA install / splash | Yes |
| `public/images/icon-180x180.png` | 180×180 PNG | Apple touch icon | Yes |
| `public/favicon.ico` / `public/images/favicon.ico` | multi-size `.ico` | Browser tab icon + manifest | No — use a dedicated tool |
| `public/icon.svg` | vector mark | Sidebar logo (`admin-shell.tsx`) | No — replace by hand |
| `public/logo.svg` | vector wordmark | Full lockup on light backgrounds | No — replace by hand |
| `public/logo-white.svg` | vector wordmark | Same lockup on dark backgrounds | No — replace by hand |

`sips` can't write multi-size `.ico` files, so `task branding:gen` skips the favicon. Generate `favicon.ico` with a dedicated tool such as [realfavicongenerator.net](https://realfavicongenerator.net) and drop it at `public/favicon.ico` and `public/images/favicon.ico`. Replace the SVGs (`icon.svg`, `logo.svg`, `logo-white.svg`) by hand — keep the same filenames and no code changes are needed.

## Where branding is wired

| File | What to change |
|------|----------------|
| `public/` | Raw assets — served from the site root. |
| `public/manifest.json` | PWA metadata: `short_name`, `name`, `theme_color`, `background_color`, and the icon set. |
| `src/routes/__root.tsx` | The `<link>` tags: `rel=icon`, `apple-touch-icon` (180×180), and the manifest link. |
| `src/components/admin-shell.tsx` | The sidebar `<img>` (`/icon.svg`) — point it at your mark. |
| `src/lib/seo.ts` | `SITE_NAME` — the title suffix on every page (`Page title · SITE_NAME`). Rename it here. |

### Update the app name

Two edits change the name everywhere it shows:

- `public/manifest.json` — set `short_name`, `name`, and `theme_color`:

  ```json
  {
    "short_name": "Volt",
    "name": "Volt — React Starter Kit",
    "theme_color": "#000000",
    "background_color": "#ffffff"
  }
  ```

- `src/lib/seo.ts` — rename the `SITE_NAME` constant:

  ```ts
  const SITE_NAME = "Volt"
  ```

## Regenerating from the brand kit

If you want a full, consistent identity — glyph, wordmark, lockups, favicon, OG social covers, and design tokens — work from the brand kit in [`../brand/`](../brand/README.md) instead of editing assets one at a time. Everything there derives from `brand.json` via `gen-brand.mjs`; edit the manifest, then regenerate:

```bash
task -t volt/brand/Taskfile.yml all
```

That rebuilds the SVGs and tokens and rasterizes the PNGs. Then copy the outputs you need into `public/` (favicon, PWA icons, `logo.svg`). See [`../brand/BRAND_GUIDELINES.md`](../brand/BRAND_GUIDELINES.md) for the full identity — colors, typography, clearspace, and the do's and don'ts.
